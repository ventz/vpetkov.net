# ventz-mods — customization backup snapshot

Snapshot of the site-level PaperMod customization overlay (`layouts/` + changed
`assets/css/` files), generated by `../generate-ventz-mods.sh`. Regenerate any
time with:

```sh
./generate-ventz-mods.sh
```

**This directory is NOT used by Hugo** — the live overlay is `layouts/` and
`assets/` at the repo root. This is a portable backup: on a fresh PaperMod
setup, drop these files into the site root to re-apply all "Ventz Changes".

Structure follows PaperMod's Hugo 0.146+ template system (`layouts/*`,
`layouts/_partials/`, `taxonomy.html`, `md-content.css`). The pre-0.146
original snapshot is preserved in git history (commit `be88440`).

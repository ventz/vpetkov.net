# ventz-mods — original customization backup

Historical snapshot of the PaperMod customizations as extracted by
`generate-ventz-mods.sh` from the old prototype site
(`~/git/private/proj/hugo/papermod`), targeting PaperMod at commit `9f1f414`
(pre Hugo 0.146 template system: `layouts/_default/`, `partials/`, `terms.html`).

**This directory is NOT used by Hugo.** The live, maintained versions of these
customizations are the site-level `layouts/` and `assets/css/` overlays at the
repo root, rebased onto PaperMod's current template structure. Kept only as a
reference for what was changed and why.

Note: `layouts/partials/header.html` in this backup is identical to the old
theme version (no actual modification) — the extraction script copied all of
`layouts/` wholesale.
